# mmatos.com.br

Site estático do escritório Maicon Matos Advocacia, publicado na Cloudflare Pages.

- `index.html`: página inicial
- `artigos/`: um arquivo HTML por artigo (o endereço fica `/artigos/nome-do-arquivo`)
- `sitemap.xml`: lista de páginas para o Google; atualizar ao publicar artigo novo
- `404.html`: página de erro

Configuração na Cloudflare Pages: Framework preset **None**, build command vazio, output directory `/`.
